## 🛠 Installation & Set Up

1. Install and use the correct version of Node using [NVM](https://github.com/nvm-sh/nvm)

   ```sh
   nvm install
   ```

2. Install dependencies

   ```sh
   yarn install
   ```

3. Start the development server

   ```sh
   yarn dev
   ```

## 🚀 Building and Running for Production

1. Generate a full static production build (written to `out/`)

   ```sh
   yarn build
   ```

2. Deploy: pushing to `main` on [KittichoteKamalapirat.github.io](https://github.com/KittichoteKamalapirat/KittichoteKamalapirat.github.io) runs `.github/workflows/deploy.yml`, which builds the site and publishes `out/` to GitHub Pages.
